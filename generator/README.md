# Generador Spring Boot

Este modulo contendra el generador propio que transforma el modelo UML validado
en un backend Spring Boot (modelo/repository/service/controller/DTO, `pom.xml`,
`application.yml` y `schema.sql`).

Se implementa en la Fase 10, una vez que existan el modelo UML, su validador y
el resto del backend de la plataforma. Por ahora queda como carpeta reservada
para mantener la separacion de responsabilidades definida en la arquitectura.
